MyNetworkMonitor für OpenWrt – Installation
===========================================

Voraussetzung
-------------
  - Router mit OpenWrt 25.12 (Status -> Übersicht -> Firmware-Version)
  - Zugang per SSH (unter Windows 10/11, Linux und macOS schon vorhanden)

Installieren
------------
  1. Am Rechner ein Terminal öffnen (Windows: PowerShell).

  2. Am Router anmelden (Adresse des Routers einsetzen):
       ssh root@192.168.1.1
     Passwort: das der Router-Oberfläche.

  3. Diese Zeile einfügen und Enter drücken:
       wget -O - https://raw.githubusercontent.com/systemswap/MyNetworkMonitor_OpenWRT_Plugin/main/packaging/install.sh | sh

  4. Router-Oberfläche neu laden: Netzwerk -> MyNetworkMonitor.

  Das Skript wählt die passende Datei für den Router, prüft sie und
  installiert sie. Aktualisieren: dieselbe Zeile noch einmal.

Router ohne Internet
--------------------
  1. Aus dem Release in einen Ordner laden:
       install.sh, SHA256SUMS, luci-app-mynetworkmonitor_..._all.apk
       und mynetworkmonitor-scan_..._<architektur>.apk
     Welche Architektur? -> GERAETE.html oder auf dem Router: apk --print-arch
  2. Im Terminal in diesem Ordner auf den Router kopieren:
       scp -O install.sh SHA256SUMS *.apk root@192.168.1.1:/tmp/
     (Windows: statt *.apk die Dateinamen ausschreiben)
  3. Am Router anmelden (wie oben) und starten:
       sh /tmp/install.sh

Wichtig
-------
  - "System -> Software -> Paket hochladen" geht NICHT (Fehlercode 99):
    Die Pakete sind nicht von OpenWrt signiert.
  - Nur Netze scannen, für die man die Erlaubnis hat. Portscans können
    empfindliche Geräte wie Steuerungen stören.

Bei Problemen
-------------
  Fehlercode 99          ohne Skript installiert und "--allow-untrusted" vergessen
  Fehlercode 2, "arch"   Scanner-Datei passt nicht zum Router (apk --print-arch)
  "cannot reach GitHub"  Router hat kein Internet -> "Router ohne Internet"
  "no scanner for ..."   für diesen Router gibt es noch kein Paket

Von Hand (ohne Skript)
----------------------
  apk add --allow-untrusted /tmp/mynetworkmonitor-scan_*.apk /tmp/luci-app-mynetworkmonitor_*.apk

Entfernen
---------
  apk del luci-app-mynetworkmonitor mynetworkmonitor-scan
